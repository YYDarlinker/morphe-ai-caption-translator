# N42 — 人工 cue 溢出、全语种分页、显示时长与“翻译中”修复记录（2026-10-19）

本文件记录 `docs/N42-ROOT-CAUSE-20261019.md` 之后实施的根修。范围是当前工作树
`dev/1.5.4-deepseek`；没有签名、安装、推送或发布。

## 0. 修复摘要

| 问题 | 修复后的权威 |
|---|---|
| 人工 cue 不可切且超过两行 | cue/group 是显示身份；>2 行显式投影为 `AUTHORED_OVERFLOW` 子页，使用同一套 clause + measured fallback；单分句 >2 行在字形边界 emergency split，不空屏、不截断 |
| `が`/`しかし` 碎片 cue 导致整块拒译 | `RebuildCueContract.groups()` 把不能独立成页的 cue 合成 display group；请求、解析、显示、缓存使用同一组边界 |
| 中文/其它语言两套分页器 | 删除 `CaptionRenderSpec.legacy` 与中文专用分页分支；所有 target 走 `CaptionLanguagePager` + `unitPages` |
| 日语/韩语/泰语被当成有空格文字 | 新增 `CaptionScript`（ICU `UScript`）；`compact`/`requiresSpace` 由 script 决定 |
| `ja→zh` 几乎没有质量门禁 | `validateTarget` 增加通用目标 script 检查；`invented_sentence_end`/`dependent_boundary`/`fragmented_plan` 去掉 en→zh 前置；CJK 虚词参与 planner |
| `4 and a half` → `4.5` 被判数字替换 | `RebuildNumbers` 改为数值等价：分数/小数/全角/分组/万/百万；只有明确一对一值冲突才拒 |
| 5–7.4 s 单页 | 时间平衡分页：阅读时间 ≥2 s 且时长超过 comfort（3–5 s）才在完整分句上切；每页 ≥2.2 s，否则保持单页 |
| 人工源首条字幕等待完整 block | `RebuildCueContract.partialUnits()`：已完整覆盖的 group 可流式先显示，未完成 group 等待 |

## 1. 具体修改

### 1.1 Display group：碎片 cue 的合并

`translation-core/.../RebuildCueContract.java`

- `VERSION` 从 `authored-cue-v1` 升到 `authored-cue-v2`。
- 新增 `groups(source, block)`：
  - 普通 cue 仍是一组；
  - 只有满足以下之一的“不能独立成页”cue 才向前合并：
    - 可见字符 ≤ 2；
    - 整段由虚词/连接词组成（`RebuildPlanner.functionWordsOnly()`，含日/韩/中虚词与
      `がしかし` 这类组合）；
    - 时长 < `MIN_GROUP_MS/2`（600 ms）。
  - 合并后的 group 继续吸收后续 cue，直到能成为可读页；block 末尾的碎片向后并入。
- `addPayload()` 的 `display_cues` 改为 group 列表；`validate()`/`units()` 的
  `byGroup`、`groupAt()`、`groupByIndex()` 全部按 group 校验/聚合。
- `partialUnits()`：流式前缀只发布完整覆盖的 group；未完成 group 不提前上屏。
- `summary()` 输出 `cues=`、`groups=`、`events_per_group=`，诊断可直接看到分组。
- 删除 `cueOf()` 等只会按原始 cue 统计的旧辅助。

实际效果（真实 `.ja.vtt`，`b12_868_892`）：

```text
CUE 47 868-868 source=が          (458 ms)
CUE 48 869-871 source=しかし      (667 ms)
GROUP 47 868-890
GROUP 50 891-892
PARSED events=3
UNITS=2
UNIT 150250-154292
UNIT 154292-157167
```

### 1.2 cue overflow：显式子页

`translation-core/.../RebuildPageLayout.java`、`CaptionLanguagePager.java`、
`RebuildController.java`

- `unitPages()` 仍保留“人工 cue ≤2 行则一页（`AUTHORED_CUE`）”的原子性。
- 超过两行时：
  - `pack()` 以整分句/一行一页生成子页；
  - 单个分句 >2 行时 `splitToFit()` 在 Unicode 字形边界上取最长可放前缀；
  - `allocate(..., "AUTHORED_OVERFLOW")` 保留 cue/group 外窗，必要时用 source anchors；
  - `CaptionLanguagePager.authoredLabel()` 给 fallback 页统一标 `AUTHORED_OVERFLOW`。
- `CaptionLanguagePager.fallback()` 在 `cuts` 找不到可放前缀时调用 `measuredPrefix()`，
  不再把整段 >2 行文本作为一页返回。
- `TranslationPresentation` 的 `fullPage()` 仅作为不可测量/非连续分区的最后兜底；正常路径
  已保证每页 ≤2 行。

探针（真实中文、8/16 字谓词、39 字 cue）：

```text
OVERFLOW_PAGES=4
  AUTHORED_OVERFLOW 这类文章获得了数百万的浏览量和关
  AUTHORED_OVERFLOW 注，它们塑造了公众舆论。
  AUTHORED_OVERFLOW 这个网站专门经营官方尚未发售的苹
  AUTHORED_OVERFLOW 果原装配件
```

每页 ≤2 行、文本连续覆盖、外窗 0–9000 ms；不再出现 `SOURCE_EVENT` 伪装的 cue 子页或空屏。

### 1.3 一个分页器 + script 事实

`caption-shared/.../CaptionScript.java`（新文件）

- `compact(Locale)`：Han/Hiragana/Katakana/Hangul/Thai/Lao/Khmer/Myanmar 为无空格文字；
- `requiresSpace(left,right)`：两个 compact 文字紧排；compact+Latin / Latin+Latin 加空格；
  标点/空白不额外加；
- `primary(locale)`：ICU 主 script，供目标文字门禁使用。

`CaptionRenderSpec`

- 删除 `legacy` 字段；`compactScript` 由 `CaptionScript.compact(locale)` 计算；
- 不再用构造器的 `chinese` 布尔值决定分页/分隔行为（保留构造签名以兼容 pinned fixtures）。

`RebuildPageLayout`

- `plan()` 对所有 target 直接调用 `CaptionLanguagePager.plan()`；
- 删除中文 `preferredLegacyPlan`、`choose`、`semanticSeams`、`expandedSeams`、`styleCost`、
  `timingCost`、`minimumMs`、`State` 等死代码（约 300 行），避免“中文专用算法”再次复活；
- `pageCuts()` 改用 `CaptionClauses.ends()`（全 Unicode clause mark）+ U+200B 事件接缝；
- `leadClause()`/`endsClause()` 改用 Unicode 标点，不再只认 CJK 半角集合。

`RebuildDisplayGroups`、`RebuildCueContract`

- 分隔符统一调用 `CaptionScript.requiresSpace`；
- compact script 的无标点事件连接仍保留 U+200B 作为不可见页切点；有标点时不再插入。

### 1.4 质量门禁去语言特判

`RebuildSemantics`

- `validateTarget()` 增加通用目标 script 检查：
  - zh/ja/ko 保留原细检查；
  - 其它 target 若译文有 >4 个字母、目标 script 命中 0、源 script 命中 >0 且与目标不同，
    抛 `target_language_mismatch`；
  - 源文回声检查对所有语言对生效。
- `validate()` 的数字范围检查去掉 `canApplyEnglishToChinese` 前置。
- 新增 `countScript(String,int)` / `scriptName(int)`；`CaptionScript.primary()` 失败时安全返回
  `-1`。

`RebuildReview`

- `dependent_boundary`、`invented_sentence_end`、`fragmented_plan` 去掉 en→zh 前置；
- `withLayoutReview()` 统一为 `presentation_geometry_observation`，不再有 `legacy` 分支。

`RebuildPlanner`

- 新增 `CJK_DEPENDENT`：日语/韩语助词、汉语虚词/连接词；
- `dependentEnding(s,i,context)` 对非英语源也识别这些虚词；
- `functionWordsOnly()` 支持 `がしかし` 这类 kana 单字切分后的整段虚词；
- `strongDependentEnding/protectedCut` 仍只对英语做硬检查，避免对无词边界语言新增误拒。

`RebuildNumbers`

- `values()`：
  - 全角/阿拉伯-印度/Devanagari 数字归一；
  - 分数：`4 and a half`、`one and a half`、`a half`、`half`、`4½`、`四个半`、`3/4`；
  - 数量级：`1万`、`1.5万`、`10k`、`2 million`、`3 billion`；
  - 分组逗号、小数。
- `safe()` 只在“两边各一个可解析数值且值不同”时 false；多值/缺值/不可解析仍 true。
- `compare()` 对所有语言对使用同一值解析；日期冲突仍优先；多值仅在多集完全一致时
  `EQUIVALENT`，否则 `UNKNOWN`；不再对非 en→zh 只比较纯整数。
- `detail(from,to,source,target)` 把 `range` + `source_values/target_values` 放进拒绝诊断，
  且不增加 `RebuildProtocol` 的 pinned literal。

### 1.5 时间平衡分页

`RebuildPageLayout.unitPages()`

- 对自动 unit：
  - `timeSplitWanted()`：非 authored、时长 ≥2×`MIN_PAGE_MS`、阅读时间 ≥2 s、时长 >
    `comfortMs`；
  - `comfortMs = clamp(reading × 1.5, 3000, 5000)`，reading = `readingUnits/referenceCps`；
  - `targetPages = ceil(duration/comfort)`，上限为内部标点数+1 与 `duration/MIN_PAGE_MS`；
  - `balancedPages()` 在完整分句上做小规模划分：优先一行，惩罚引子/残尾，按阅读权重
    估计每页时长；任一页估计 <2.2 s 则放弃切分，宁可不切；
  - `allocate()` 按阅读权重分配，source anchors 可用时落在真实停顿上；
  - 单分句即使很长也不为时长硬切（保留 `aLongUnbrokenClauseStaysOneTwoLinePage`）。
- 人工 cue ≤2 行仍 `AUTHORED_CUE` 单页；>2 行走 overflow 子页。

探针（真实中文）：

```text
TWO_CLAUSE_7S_PAGES=2
  4156ms 这类文章获得了数百万的浏览量和关注，
  2844ms 它们塑造了公众舆论。
ONE_CLAUSE_9_6S_PAGES=1
```

### 1.6 人工流式预览

`RebuildController.displayUnits()`

- 对 authored track 判断 `s.provisional[index] == plan`：
  - provisional → `RebuildCueContract.partialUnits()`，完整 group 立即显示；
  - 完整 plan → `units()`，继续严格 group 覆盖。
- `REBUILD_UNIT_MODE` 增加 `partial=true/false` 与 group summary。
- 缓存仍按 `plan + geometry`；流式前缀变化会重新计算，完整 plan 到达后替换。

## 5. 仍未解决/边界

1. **未真机/未安装**：本轮没有连接或写入手机；新 MPP 的实体安装、ABI/组合和 after 诊断
   待用户复验。
2. **语义质量仍由供应商模型决定**：本轮只消除格式/数值/分组误判与分页结构错误，不新增
   语义裁判。
3. **碎片判定是保守集合**：2 字 cue 也会合并；若真机 after 诊断显示作者页被过度合并，
   可调整 `fragment()` 的虚词/时长阈值，而不改结构。
4. **单分句 >2 行**：只能在分句内部 emergency split；这是“不空屏”与“不断语义”的取舍。
5. **数值数词**：中文 `二十`、阿拉伯语数词等仍未解析为值；保持 `UNKNOWN`（不硬拒，但也
   不证明等价）。
6. **语言参数**：`referenceCps/referenceCpl` 仍是人工数据；日语 4 cps、500 ms 最小页等
   需要母语验收，本轮不把它们改成统一平均。
7. **流式 partial**：只发布完整 group；如果模型把整个 block 的第一个 group 也合并/延迟，
   仍会等到该 group 完整，但不会先上屏错误分页。
