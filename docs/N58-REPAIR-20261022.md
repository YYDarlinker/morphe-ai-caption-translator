## 0. 一句话

把字幕从“视频 Surface 祖先链里会重排的 TextView”改成“播放器 controls 内容层的稳定图层”，
再加一层只消费字幕矩形内 DOWN 的透明触摸代理；字号/分页/框宽由**真实播放器视口档位**决定，
几何动画只做 translation，停稳后不再重排。

### 1.1 宿主与 z 序

- 视觉层：`inset_overlay_view_layout`（controls 内容层，FrameLayout）index 0——视频之上、
  播放器控件之下、评论面板之下。
- 触摸层：`player_overlays_custom_views_container`（YouTube `bringChildToFront` 的层，控件之上、
  评论之下）全屏透明 View；DOWN 在字幕 `TextView` 的 `getGlobalVisibleRect()` 内才消费，
  否则返回 false 继续传给 YouTube。
- Shorts：视觉/触摸都优先 `reel_player_overlay_root`；评论仍在其上。

### 1.2 字号与分页

- `FULL`：全屏字号（短边 1264 → 55.5 px）；`REDUCED/DETAIL/SHORTS_REDUCED`：详情字号（44.5 px）；
  `SHORTS_FULL`：全屏字号。所有值按 `min(screenW,screenH)/1264` 缩放。
- 横屏 2736×1264 + 评论打开（视频 1478×831）：`REDUCED`，44.5 px；不再出现旧实现按屏幕宽度
  算出的 96 px 或按视频宽度算出的 36.5 px。
- 档位只在跨阈值时提交一次新 plan；停稳后 `canReuseCommittedPage()` 不再检查“当前页是否放得下”，
  因此不会在动画结束时重排。

### 1.3 稳定框

- 每个 plan 取所有页的 `max(line1Px,line2Px)` 与最大行数（1/2），一次设定 TextView 的宽与
  `minHeight`；翻页只换文字，不再重设宽高。
- anchor 宽度 = 档位 frame 宽度（`0.92×` 或 Shorts `0.78×`），动画期间不变。
