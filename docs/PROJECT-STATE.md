1. **任务卡制**：每张卡一个封闭任务，新会话执行，做完即停；汇报 ≤半页（改动文件、分数、建议不执行）。

7. **真机规则**：真机发现新问题不现场改，记录时间位置+现象，回流为 ACCEPTANCE.md 新案例。
