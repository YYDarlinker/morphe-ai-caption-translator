## Awesome Morphe Bundle Request

Action: Add Bundle

Repository URL: https://github.com/YYDarlinker/morphe-ai-caption-translator

Description:

Anchored AI Captions is an independently maintained, GPLv3 patch bundle for YouTube. It translates existing video subtitles using an OpenAI-compatible API configured by the user. It provides caption styling, configurable languages in the native Auto-translate menu, profiles, caching and diagnostics. Caption language remains owned by YouTube and the official Captions patch; the addon follows that native selection. It is designed to be selected alongside compatible official Morphe patches, not to replace them.

Release 1.5.5 publishes a single public patch, **AI caption translator**. Recommended combination: official Morphe Patches 1.47.0, original YouTube 21.20.405, Android 9+. These are not claims of complete device testing for every combination. The repository distributes patch code, not pre-patched YouTube APKs.

## Reddit introduction

Title: Anchored AI Captions 1.5.5: YouTube subtitle translation with your own API

I maintain Anchored AI Captions, an independent open-source patch bundle compatible with Morphe. It translates a video's existing subtitles using an OpenAI-compatible API you configure. Select a target in YouTube's Auto-translate menu while AI captions are enabled; original subtitle selections do not call the translation API.

It supports regular videos, full-screen playback and Shorts, caption styling, API profiles, configurable target-language entries and diagnostics.

Use Expert mode with the compatible official patch set. The recommended combination is official 1.47.0 + original YouTube 21.20.405 on Android 9+. You need existing video subtitles and your own API account; provider/network latency and token charges apply. This is not an audio transcription service, and perfect subtitle timing or every OEM scenario is not guaranteed.

Source, setup and limits: https://github.com/YYDarlinker/morphe-ai-caption-translator
